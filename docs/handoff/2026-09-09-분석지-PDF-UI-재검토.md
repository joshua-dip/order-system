## 검토 범위와 결론

사용자가 제공한 Downloads의 「26년 9월 고1 영어모의고사 분석지 · 해설편.pdf」를 8쪽 모두 이미지로 렌더링해 검토했다. 파일 생성일은 2026-09-09, 내용은 **18번·19번 두 지문**이다. 25개 지문 전체 또는 31번이 포함된 파일은 아니다. 아래 페이지 번호는 PDF의 실제 쪽수다.

판정: 반의어·중첩 괄호 등 표기 정확성의 개선은 확인된다. 본문과 바로 아래 해설을 함께 읽기 쉬운 기본 구성도 장점이다. 다만 작은 주석, 끊어진 라벨, 긴 구절 뜻으로 벌어지는 단어 간격, 탐색 수단과 글 흐름 도식의 부재가 남아 있다. 기존 상세분석지의 정보량을 갖추었지만, 중요도에 따라 시선을 안내하는 설계는 추가 개선이 필요하다.

실제 종이 인쇄 시험은 하지 않았다. 인쇄 가독성 평가는 A4 렌더링과 조판 코드의 글자 크기를 근거로 한다. 수정 전 PDF의 결함을 현재 파일에서도 발생한 것으로 간주하지 않았다.

## 우선순위별 개선 사항

### 1. 출력 결함과 작은 표기를 먼저 수정

**4쪽 문장 4:** 구문 라벨 「전치사구」가 줄 끝에서 「전치」와 다음 줄 「사구」로 쪼개진다. 라벨만 남은 줄 때문에 본문과 해석 사이에도 큰 빈 공간이 생긴다.

**6쪽 문장 2:** 「시간 부사절」 라벨도 줄을 넘어간다. 괄호 순서는 맞아졌어도 어디까지가 한 구문인지 시각적으로 다시 추적해야 한다.

개선: 닫는 괄호와 라벨을 하나의 줄바꿈 불가 단위로 묶는다. 아주 긴 라벨은 별도 주석 행으로 이동한다. 전체 문장을 한 줄로 강제하지 않는다. 현재 코드 기준 구문 라벨 6pt, 단어 뜻 6.4pt, SVOC 6.5pt이므로 7~8pt 범위의 시안을 실제 A4 크기로 비교한다. 확대에 따른 쪽수와 충돌도 함께 확인한다.

**각 쪽 하단:** 교재명·판 이름의 한글이 사라지고 「26 9 1 ·」처럼 숫자만 남는다. **7쪽 어법 집계**에서도 「과거분사」 뒤의 문장 번호 ⑪가 보이지 않는다. 본문과 별도로 생성되는 푸터에 한글 폰트를 적용하고, 원문자 ⑪ 지원 또는 일반 숫자 대체를 확인한다.

완료 기준: 라벨 낱글자만 남는 줄 0건, 한글 푸터 정상, 11번 문장 참조 정상.

### 2. 단어 뜻을 실제 영어 구절과 함께 배치

**4쪽 문장 3·4:** field trip의 뜻 「현장체험학습」이 field에 매달려 영어 단어 간격을 벌린다. **6쪽 문장 6:** sing along의 「함께 따라 부르다」도 같은 문제가 있다.

개선: 여러 단어로 된 어휘는 해당 구절 전체 아래 뜻을 가운데 정렬한다. 지나치게 긴 뜻은 짧은 본문 뜻과 어휘 표의 전체 뜻으로 분리한다. `field trip`, `sing along`이 시각적으로 한 덩어리로 보이는지 확인한다.

### 3. 강조의 위계와 글 흐름을 재설계

4~7쪽은 노란 주제문, 분홍 서술형 배경, 연두 어휘, 분홍 연결어, 빨간 밑줄, 여러 색의 SVOC·괄호가 한 문장 안에 겹친다. 핵심 정보가 있어도 먼저 볼 곳이 분명하지 않다.

개선: 영어 본문은 기본색, 핵심 근거는 한 가지 강조색, 어법 주의는 보조색을 중심으로 구성한다. 문장 전체 배경색은 꼭 필요한 문장에 제한하고 나머지는 여백 배지나 얇은 선으로 표시한다. 색에 더해 글자 라벨을 유지해 흑백에서도 구별되게 한다.

19번은 일반 설명문의 「주제문」보다 「전환점」「결말·심경」처럼 문장 역할을 표시하는 편이 복습에 유용하다. 7쪽의 긴 글 흐름 설명 위에 다음과 같은 도식을 배치할 수 있다.

- ①~④ 혼자 노래하며 긴장
- ⑤~⑦ Durwood 등장과 도움
- ⑧~⑪ 긴장 완화와 함께 마무리

5쪽의 변형문제 예상은 8유형 중 7개, 7쪽은 8유형 중 6개가 강조되어 우선순위 판단에 도움이 제한적이다. 주력 2~3개와 추가 연습 유형을 구분하고 본문 근거 문장을 연결한다.

### 4. 짧은 배포용과 책자용을 구분

총 8쪽 가운데 본문은 4~7쪽의 4쪽이다. 표지 1쪽, 목차 1쪽, 안내 1쪽, 판권 1쪽이 나머지 절반을 차지한다. 특히 2쪽 목차는 두 항목만 있는데 한 쪽을 사용한다.

개선: 소수 지문 선택 시 「수업 배포용」을 기본 제안한다. 표지·목차를 생략하고 안내는 본문 상단의 짧은 범례로, 판권은 마지막 쪽 하단으로 합친다. 현재 본문 배치를 유지하면 두 지문은 4쪽 구성이 가능하다. 여러 지문을 묶는 책자용에서는 표지와 목차를 유지한다.

2쪽 목차의 1·2는 지문 순번이며 실제 시작 쪽 4·6을 제공하지 않는다. 「18번 … 4쪽」「19번 … 6쪽」과 PDF 북마크·이동 링크를 제공한다. 4·6쪽 머리말의 「p2」는 원문 페이지임을 「원문 p.2」로 명시하고 PDF 쪽수와 구분한다. 5·7쪽처럼 이어지는 쪽에도 해당 문항 번호를 작게 반복한다.

### 5. 표를 읽기 쉬운 요약과 복습 도구로 변경

5·7쪽 종합분석에서 주제·요지·요약의 설명이 겹치고, 글 흐름·출제 포인트는 긴 산문이다. 상단 한 줄 요약과의 중복도 있다.

개선: 주제 1줄 → 흐름 도식 → 핵심 근거 2개 → 주의할 오답 2개로 압축한 수업용 옵션을 제공한다. 상세 해설은 교사용 양식에 유지한다. 7쪽 어휘 표의 「품사」가 두 줄로 쪼개지므로 해당 열의 최소 폭과 줄바꿈 규칙도 정리한다. 어휘 표는 체크 칸이나 뜻 가리기 버전으로 복습에 연결한다.

본문 옆에 넓은 사이드바를 반드시 추가할 필요는 없다. 지문 끝에 「심경 변화의 근거 표현 2개 찾기」「with+목적어+분사의 형태 설명하기」처럼 짧은 확인 활동을 넣어도 된다.

## UI 외에 발견된 잔여 내용 오류

5쪽 18번 「글의 흐름」은 아직 「감사 인사(1) → 안내 목적 제시(2) → 원래 계획(3) → … 변경 사유(4~5) → 변경 결정 통보(6)와 새 장소·활동 상세(7) → 협조 요청(8)」로 적혀 있다.

본문의 1번은 Dear Parents and Guardians라는 호칭이다. 실제 대응은 감사 2, 안내 목적 3, 원래 계획 4, 변경 사유 5~6, 변경 결정 7, 새 장소·활동 8, 협조 요청 9다. 19번의 번호 보정은 확인됐지만 18번에는 같은 문제가 남아 있다. 흐름 도식 도입 전 이 참조 관계부터 바로잡아야 한다.

- `lib/analysis-sheet-html.ts`: `renderSentence`(괄호·라벨·글로스), `passagePages`(문장·해설 블록, 글 흐름·표), `vocabTables`, `examTypeChips`, `circ`, `buildAnalysisSheetHtml`(표지·목차·안내·판권), CSS.
- `lib/analysis-sheet-load.ts`: 저장 데이터와 출력 데이터의 위치·형식 정규화.
- `app/api/admin/syntax-analyzer/analysis-sheet-pdf/route.ts`: PDF 조판·여백·푸터.
- `lib/pdf-korean-font.ts`: 한글 폰트. 본문과 PDF 푸터의 폰트 적용 경로는 별도로 확인할 것.

1. 출력 결함: 끊어진 라벨, 푸터 한글, ⑪ 누락, 18번 문장 참조부터 재현·수정.
2. 가독성: 여러 단어 어휘의 뜻 배치, 작은 주석 크기, 문장+해석+해설의 페이지 경계 처리.
3. 학습·편집 옵션: 수업 배포용, 흐름 도식, 강조 위계, 확인 활동과 탐색 수단.
