# 쏠북 업로드 계획 (2026-09-27)

**방향**: 맥(order-system 세션) 분석 → Windows 세션이 업로드·제작에 사용
**원본 데이터**: `docs/solvook/data/` · 보기 좋게 옮긴 페이지: `docs/solvook/solvook-priority.html` (브라우저로 열기)

쏠북 저자센터(partner.solvook.com)에 있는 영어 출처 교재 294권을 대상으로 다음 네 가지를 교재명으로 맞췄다.

- 라이선스 상태
- 이미 올린 자료와 판매 실적
- 영어 유료 라이선스 비용표
- 고미조슈아 DB의 지문·변형문제 보유량

이를 바탕으로 **무엇부터 올리거나 만들지** 순서를 매겼다.

---

## 1. 결론

1. **라이선스는 「보유」(자료 그룹 만들기 화면의 「선택」)를 먼저 쓴다.**
   - 보유는 이미 확보된 라이선스라 추가 비용이 없다.
   - 「획득」은 올릴 때는 0원이다. 하지만 구매자 수 구간(5명 → 100명 → 500명…)을 넘을 때마다 정산금에서 비용이 빠진다(Type A 후차감).
   - EBS·모의고사·마더텅·자이스토리는 비용표상 0원이다.
2. **A단계 24권은 바로 올릴 수 있다.**
   - 보유 라이선스이거나 무료로 획득할 수 있고, DB에 문제가 이미 있는데 쏠북에는 아직 없는 교재다.
   - 맨 위는 올림포스 전국연합 기출 고1이다. 지문 280개, 끌어온 문항 10,846개(아래 4절 참고).
3. **S단계 30권은 이미 팔리고 있다.**
   - 수능특강·고1~고3 모의고사 등이다.
   - 새로 올릴 것보다 **빠진 강·번호·유형을 채우는** 보강이 먼저다.
4. **B단계 34권**은 보유 라이선스이고 지문도 DB에 있지만 문제가 0이다. 변형문제를 만든 뒤 올린다.
   - 이 중 기출문제집(수능 기출의 미래, 올림포스 기출 고2 등)은 **새로 만들지 않고 원출처 모의고사 문항을 끌어오면 된다.**
5. **C단계 53권**은 보유지만 DB에 지문이 없다. 지문 입력부터 해야 해서 비용 대비 느리다.
6. 획득(유료)인 D·E·F는 수요 근거(우리 사이트 주문, 쏠북 판매 실적)가 생긴 뒤로 미룬다.
7. 쏠북 라이선스 목록에 없는데 우리 DB에는 문제가 많은 교재가 있다(동아·미래엔·천재 교과서 등).
   - 우리 사이트 「쏠북」 표시 66권 중 34권이 여기에 해당한다.
   - 쏠북에서 팔려면 출판사가 라이선스를 열어야 한다.

## 2. 우선순위 기준

| 단계 | 조건 | 할 일 |
|---|---|---|
| **A** | 보유(또는 무료 획득) · DB 문제 있음 · 쏠북 미등록 | 바로 자료 그룹 만들어 등록 |
| **S** | 쏠북에서 이미 판매 중 | 빠진 강·번호·유형 보강 |
| **B** | 보유(또는 무료 획득) · DB 지문 있음 · 문제 0 | 변형문제 제작(기출문제집은 끌어오기) 후 등록 |
| **C** | 보유 · DB 지문 없음 | 지문 입력 → 제작 → 등록 |
| **D** | 획득(유료) · 문제 있음 / 무료 획득 · 지문 없음 | 수요 확인 후 |
| **E** | 획득(유료) · 지문 있음 | 수요 확인 후 |
| **F** | 획득(유료) · 지문 없음 | 보류 |
| **X** | 「구매」(선결제) 라이선스 | 보류 |
| **Z** | 어휘·문법서·초등 — 지문 변형용 교재 아님 | 대상 아님 |

단계 안에서는 DB 문제 수 → 지문 수가 많은 순, 같으면 라이선스 비용이 싼 순이다.

## 3. 올리는 단위(패키징)

지금 모의고사는 **번호별 · 카테고리(유형별) · 전체** 세 단위로 편집해 올리고 있다. 부교재·교과서는 강과 번호가 있으니 같은 틀을 한 단계 늘린다.

| 교재 종류 | 단위 |
|---|---|
| 모의고사 | 번호별 / 유형별 / 전체 |
| 부교재·교과서 | **강별 번호별** / **강별 유형별** / **강 전체** (필요하면 교재 전체) |

판매 기록에서 본 것은 다음과 같다.

- 모의고사는 **번호별**이 가장 많이 팔린다.
- 교과서는 **강 전체**의 자료당 거래액이 가장 높다.
- 우리 DB는 강별 문항 수가 고르지 않다. 그래서 강 단위 상품은 올리기 전에 문제수 시각화 → 해당 교재 → 「강별」 보기에서 빈 강이 없는지 먼저 확인한다.

## 4. 기출문제집 = 원출처 문항 끌어오기 (같은 날 합의)

- 기출문제집(올림포스 전국연합 기출, 수능 기출의 미래, 마더텅, 자이스토리 등)의 지문은 모의고사 원문이다.
- 부교재에 기출 지문이 섞여 있는 경우도 같다.
- 원칙: **기출 교재 자체의 문제 DB는 0이 맞고, 원출처(모의고사) 지문의 변형문제를 끌어와 쓴다.**

웹앱 쪽 구현은 브랜치 `feat/exam-origin-pull` 에 있고 아직 배포 전이다.

- 지문의 `original_passage_id` 또는 `passage_source`(원출처 source_key)로 원출처를 찾는다: `lib/exam-origin.ts`.
- 주문 부족분·새 문항 저장·예비시험지·주문 PDF가 모두 원출처 지문을 본다.
  - 기출 지문으로 저장해도 원출처 지문에 저장된다.
- 문제수 시각화·관리 목록은 끌어온 문항을 **「끌어옴」(하늘색)**으로 따로 보여 준다.
  - 교재 합계에는 넣지 않는다. 원출처 교재 쪽에 이미 세어져 있기 때문이다.
- 올림포스 기출 고1의 자체 문항 4,379건은 원출처 모의고사 지문으로 **옮겼다**.
  - 백업: 맥 `next-order/.tmp/backup-exam-origin-move-2026-09-27T12-54-53-998Z.json`
  - 각 문서에 `moved_from` 이 남아 있다.
  - 결과: 자체 0 · 끌어옴 10,846.
- 다른 기출 교재는 지문 연결(`passage_source`)을 먼저 해야 한다. 연결 후보 목록은 아직 원장님 확인 전이다.

**쏠북에 올릴 때**: 기출문제집 상품은 원출처 모의고사 문항으로 구성한다. 교재 목차(UNIT·번호)는 기출 교재 쪽 `source_key` 를 따른다. 문제수 시각화 드릴다운의 소스 이름이 기출 교재 목차이고, 그 옆에 「끌어옴 · 원출처」가 적혀 있다.

## 5. 저자센터 조회 방법 (읽기 전용)

브라우저에서 partner.solvook.com 에 로그인한 상태로 `api-dashboard.solvook.com` 을 호출한다.
헤더는 `Authorization: <accessToken 쿠키 값>` 이다. **Bearer 를 붙이지 않는다.** 토큰은 어디에도 적거나 저장하지 말 것.

| 용도 | 경로 |
|---|---|
| 판매 자료 목록 | `GET /partner/handouts?limit&offset&type=HANDOUT_TITLE[&q=][&baseSourceIds[]=]` |
| 자료 필터(출처 교재 목록) | `GET /partner/handouts/filter` |
| 출처 교재·라이선스 상태 | `GET /partner/products?subject=EN` → `licenseStatus`(보유/획득/구매), `freelicense` |
| 정산 | `GET /partner/settlements?type=separate&startDate&endDate` |

- 라이선스 비용표: 쏠북 가이드에 연결된 「영어 유료 라이선스 목록」 구글 시트(CSV 내보내기 → `data/license-sheet.csv`)
- 주의: 대시보드에서 뜨는 팝업 탭이 열려 있으면 다른 탭 조작이 막힌다. 먼저 닫는다.
- **「획득」·「선택」 클릭과 자료 등록은 사람이 직접 한다.** 에이전트가 누르지 않는다.
