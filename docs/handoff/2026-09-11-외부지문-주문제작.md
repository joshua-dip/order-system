# 외부지문 변형문제 주문 (XV) — 제작기 참고

**방향: 웹앱 → 제작기** · 2026-09-11

회원이 자체 지문·타 출판사 지문을 **붙여넣어** 변형문제를 주문하는 메뉴(`/external`)가 생겼다.
제작기 입장에서 새로 알아야 할 것은 **주문번호 접두사 `XV`** 하나다. 나머지는 부교재 변형과 같다.

## 무엇이 들어오나

| 항목 | 값 |
|---|---|
| 주문번호 | `XV-YYYYMMDD-NNN` (EV 는 EBS 용으로 잡혀 있어 X 를 썼다) |
| `orderMeta.flow` | **`bookVariant`** — 부교재 변형과 같은 모양이라 job 라우트·`cc:variant pipeline:XV-…` 가 그대로 동작 |
| `orderMeta.selectedTextbook` | `외부지문_<loginId>` — 그 회원 **전용 교재**. 다른 회원 주문 화면에는 뜨지 않는다 |
| `orderMeta.selectedLessons` | `<자료 이름> 01번` … (= passages.source_key) |
| `orderMeta.external` | `true` |
| `orderMeta.memberQuotaExempt` | `true` — 멤버십 무료 한도 집계에서 빠진다 |
| `orderMeta.externalPricing` | `{ multiplier: 1.3 }` |

지문은 주문 직전에 `passages` 에 등록된다(`created_from: 'member_external'`, `owner_login_id`).
`content.original` 만 있고 문장 분리·번역은 비어 있다 — 제작에 필요하면 제작 쪽에서 채운다.

## 가격 (웹앱이 계산해 주문서에 찍는다)

무료 유형·멤버십 무료 문항 없음. 부교재 변형 정가의 1.3배를 10원 단위 반올림.

| 유형 | 부교재 변형 | 외부지문 |
|---|---|---|
| 기본난도 (주제·제목 등 원래 무료 7종 포함) | 50원 (7종은 0원) | **70원** |
| 고난도 13종 | 80원 | **100원** |
| 순서·삽입 해설 포함 / 문제·답만 | 50 / 30원 (무료) | **70 / 40원** |

포인트 결제·대량 할인(100문항 10%·200문항 20%)은 그대로 적용된다.

## 제작기에서 확인할 것

1. 주문을 **접두사로 걸러 받는 곳**이 있으면 `XV` 를 추가해야 한다(`BV`·`MV` 만 받으면 XV 주문이 누락된다).
2. 지문이 새로 등록된 것이라 **재고가 0** 에서 시작한다 — 전 문항 신규 생성이다.
3. 생성 문항의 `textbook`·`source` 는 위 `selectedTextbook`·`source_key` 와 정확히 같아야 한다.
